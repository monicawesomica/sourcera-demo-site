How to connect your keys privately
  1. Create an OpenAI API key and an ElevenLabs API key in their official dashboards.
  2. On your computer, open Set up AI.command in the project folder. Paste the keys into its private prompts.
  3. Open Review Voice.command. The fictional demo opens at http://127.0.0.1:8766/.
  4. Return here, load your voices and preview a short sample. Full generation remains paused.

Never enter an API key in the Voice ID field or put one in the shared website. The public preview cannot use keys stored on your computer.
